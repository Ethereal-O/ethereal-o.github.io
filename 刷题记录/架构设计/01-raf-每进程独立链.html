单文件、多进程并发追加、崩溃可恢复。写入返回 index，支持按 index 点读与顺序迭代。

  • 并发模型：多进程 · 每进程多线程
  • 记录长度：几 B ~ 1 MB
  • 持久化：O_DIRECT + FUA

1. API 语义与文件格式

API 契约

append 的返回即代表已持久化。 没有单独的 sync() / flush() —— 返回本身就是持久点。
数据未落盘之前该调用必须阻塞。

不变式
A1 append 返回 index ⟹ 该记录已持久；崩溃重启后必定能通过该 index 读到
A2 append 未返回（阻塞中崩溃）⟹ 无任何承诺，该记录通常丢失
A3 append 返回错误 ⟹ 该记录是否可见未定义；调用方应视为失败，重试需自带幂等键
A4 调用期间 buf 必须保持有效且不被修改 —— 实现为零拷贝，IO 直接引用调用方内存
A5 调用不可取消、不可超时返回；一旦进入队列就必须等到终局
A6 顺序：两次 append 之间若存在 happens-before，则 index 单调递增；并发调用之间顺序未定义
A7 迭代是 at-least-once：可能读到数据完好但 append 从未成功返回的记录，上层需自带幂等键去重

吞吐的直接后果： 因为 append 阻塞，单个调用线程的吞吐上限 = 1 / 端到端延迟。
要打满设备必须有足够多的并发调用方（线程 / 进程），由实现侧攒批摊销 IO 成本。
这条契约也决定了下面格式设计的核心取向：一切结构都服务于「已 ack 的数据绝不可丢」。

布局

结构

三条格式铁律

  • F1 数据区零元数据。 所有描述信息都在 MetaUnit 里。4096 字节的 payload 正好占 1 扇区，开销为 0。
  • F2 分配按扇区粒度。 扇区是写入的最小单位，两个进程共享一个扇区必然互相覆盖。块内记录则完全不对齐。
  • F3 永不回写任何字节。 写 MetaUnit#N 之前先 fetch_add 预留 #N+1 的位置，链始终向前声明，不存在回填指针。

每个进程独占一条链。Slot 只在崩溃时消耗（干净退出的链可被安全接管续写），用尽后滚动到新 segment。

2. 写入与读取流程

写入

  1. 写线程把请求 push 进进程本地 MPSC 队列（一次 XCHG），阻塞在本地 futex。
  2. 本地 leader 摘下一批，打包成一个 DataChunk（varint 密排），计算 data_crc。
  3. fetch_add 共享 cursor 两次：DataChunk 的扇区、下一个 MetaUnit 的位置。
  4. 并发提交两个 IO，均带 FUA：MetaUnit（含本批 Entry 与 next_offset）与 DataChunk。不等待、不排序，继续处理下一批。
  5. 两个 CQE 都回来 → ack，按链序释放 futex 唤醒。

ack ⟺ durable。 index 只在两个 IO 都持久后才返回。崩溃时仍在队列、打包中或在飞的记录一律丢失 —— 它们从未 ack，符合契约。

读取与恢复
点读 index → 读 DataChunk → 验 data_crc → 跳到块内偏移。一次 IO。
迭代 走链 → 每个 Entry 读一块 → 块内 varint walk 逐条产出。
恢复 读 SuperBlock → 并行走 N 条链，各走到第一个无效 MetaUnit 即为该链终点 → 逐 Entry 验数据 crc，不过即为从未 ack，跳过 → cursor = 已知最大 offset + 安全边距（跨过死进程可能仍在飞的 IO）。

恢复从不扫描数据区。数据区的空洞没有任何人会去读，因此不需要 magic 搜索、resync 启发式或误判概率论证。

3. 好处与坏处

好处

  • 恢复是指针追踪，不扫描数据区：无需 resync、magic 搜索、概率论证或 GAP_BOUND 配额
  • 数据区零对齐浪费；扇区整数倍的 payload 开销为 0
  • 快路径只有一个 fetch_add；零拷贝，数据直接从进程自己的内存 DMA
  • 永不回写 ⟹ 已 ack 的数据不可能被任何后续写破坏
  • 故障隔离：一个进程崩溃只终止它自己的链

坏处

  • 每次 flush 两个 IO（并发发出，延迟不叠加，但 IOPS 翻倍）
  • 空洞永久泄漏：每次崩溃漏掉一段已分配未写入的空间
  • Slot 数量有限，崩溃时消耗，用尽需滚动 segment
  • 跨链无全局顺序；需要的话得加逻辑时间戳 + 读侧归并
  • 小记录仍依赖进程内攒批摊销 Entry 开销（否则每条 20 B）
  • 恢复需走完整条链；链头 checkpoint 可加速，但那是设计中唯一的原地重写
  • at-least-once：迭代可能看到数据完好但从未 ack 的记录，上层需自带幂等键

待定参数：slot_count · meta_unit_size · flush 触发阈值 · 安全边距 · segment 滚动尺寸
